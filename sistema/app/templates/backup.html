Como restaurar um backup
  1. Feche a janela preta do sistema (a do INICIAR.bat).
  2. Na pasta Ferramentas, dê dois cliques no RESTAURAR_BACKUP.bat.
  3. Escolha o backup pelo número (Enter = o mais recente) e digite RESTAURAR para confirmar.
  4. Abra o sistema de novo pelo INICIAR.bat.

Antes de restaurar, o sistema guarda uma cópia dos dados atuais: dá para voltar atrás. Passo a passo completo (inclusive para um computador novo) no manual Manuais\2 - Backup e restauracao.md.
